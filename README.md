# UIEnhancements
Enhances the in-game UI with freedom of customization

---

## Overview
**UIEnhancements** is a Beat Saber mod that lets you add clean background panels behind your game menus. You can easily change colors, make them see-through, add borders, and set them up all at once or style each menu differently.


Everything can be adjusted directly from an easy-to-use menu inside the game.


The mod also features support for other mods like Beatleader and BSPlus.
DM `zjavierf` on discord for any mods you would like to see with a background.

## Features & Supported UI Panels

Choose which menus get a nice background panel:

- **Level Selection Background**: Adds a backdrop behind the song selection screens.
- **Gameplay Settings Background**: Cleans up the look behind your modifiers and setup options.
- **Leaderboard Background**: Frames the score leaderboards nicely.
- **Song List Background**: Optional backdrop right behind your song list.
- **Mods Background**: Styles the mod list menu.
- **BeatLeader News Background**: Adds a background to the BeatLeader news board.
- **BS+ Menu Music Background**: Wraps around the music player interface.

### Customization Options
- **Global & Selective Control**: Style everything at once with one click, or turn on individual settings if you want specific menus to look different from the rest.
- **Borders & Transparency**: Easily tweak how see-through your panels are, pick custom colors, and add styled borders with their own colors and transparency.
- **In-Game Settings**: Change any option on the fly by opening the **UI Enhancements** menu button right from the game.

## Installation
1. Download the latest `.dll` file from the releases page.
2. Drag and drop it straight into your main Beat Saber `Plugins` folder.
3. Make sure you have the required mods installed (**BSML** and **SiraUtil**).
